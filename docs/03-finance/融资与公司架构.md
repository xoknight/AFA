# 融资与公司架构（分阶段演变）

## 五项原则
1. 融资主体与业务主体分离（BVI 融资 / 内罗毕业务）；2. 香港作为中国业务联动接口（预留 WFOE 母公司位置）；3. 分阶段演变、事件触发、只做加法；4. 三轨分账；5. 干净的钱（KYC/AML；不采用蚂蚁搬家/对敲——董事会红线）。

## 第一阶段（本轮）：BVI → 香港 ＋ 内罗毕
```
创始团队(37号文) + 种子轮投资人($150万/约10%) + CB认购人
                │
     AFA Holdings（BVI）— 融资主体
        │ 100%              │ 100%
 AFA 香港有限公司        AFA 内罗毕公司 — 业务主体
 中国联动接口/结算        承接 Sigma 数字化与平台运营
 (预留: 控内地WFOE)      (预留: 控飞快达等业务公司)
        ┊ 商业合同联动          ┊ 服务合同
 国内业务(现阶段)          Sigma(独立核算, 天使客户)
```

## 第二阶段（业务扩张期，事件触发）
香港 → 100% 内地 WFOE（中国揽货端，触发：中国端业务启动）；内罗毕升级区域控股 → 飞快达运营公司 + 国别公司（触发：跨境闸门达标）；ESOP 10–15%（触发：A 轮前）。

## 第三阶段（上市准备期）——2026-08-02 修订：减持层上移
层级（自上而下）：**家族信托 + 持股平台（股权税筹层：开曼/迪拜等，跟踪个税全免规则）→ BVI 中间控股层（上市公司的机构股东，创始人场外减持与传承在此层完成）→ 开曼上市主体（公众股东在此层）→ 香港/WFOE、内罗毕/国别公司两翼（+ 运营税筹层：芬兰等欧洲法域，研究项）**。
修订理由：上市公司控股子公司的股权转让可能触发 SEC 审查、交易所问询与股价波动；把减持安排放在上市主体之上的机构股东层，股权变动发生在股东层面，冲击与披露负担更小。税筹选址均为研究方向，须税务顾问验证。纳斯达克 IPO 主选、De-SPAC 备选。

## 投资人进入路径（优先级）
① 境外美元/港币直投 BVI 或 CB（2–4 周）；② 超额 → CB；③ 人民币 → ODI（3–6 月）/境外存量资产/CB 过桥；④ 政府基金 → 二阶段投 WFOE；⑤ 上市公司 → CB 先行后转股。
