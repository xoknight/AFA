## 单位经济（客户净收入=100）

## 营运资金
缺口 ≈ 月承运采购 ×（DSO−DPO）÷30 + 缓冲（示例：月收入 $350k → 占用约 $450k）。四层来源：预充值押金 50% / 银行保理 30% / 自有 ≤20% / 禁止短贷长投。
