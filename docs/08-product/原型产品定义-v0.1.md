# AFA 控制塔原型产品定义 v0.1

> 日期：2026-08-06
> 状态：首轮可点击原型；用于团队评审、Sigma 现场访谈与投资人演示，不作为生产系统需求冻结稿。

## 1. 原型要回答的问题

非快达的首个产品不是一个需要客户下载的新 App，而是一条可验证的交易闭环：

**客户在微信 / WhatsApp 发来询价 → AI 将非结构化需求转成订单 → 生成分段透明报价 → 人工确认并锁价 → 运单九环节留痕 → 客户通过免登录链接查进度 → POD 与对账自动归档。**

原型只验证三件事：

1. 运营是否能用一个页面掌握今日风险、待办和运单状态；
2. 报价是否能从“聊天内容”快速变成可审计、可确认的标准报价；
3. 客户是否能在不安装 App 的前提下清楚知道货在哪里、下一步是什么、谁在负责。

## 2. 核心角色

| 角色 | 主要任务 | 原型覆盖 |
|---|---|---|
| AFA / Sigma 运营 | 接单、校验资料、报价、派单、处理异常、回传 POD | 完整覆盖 |
| 中国货主 / 货代 | 提交需求、确认报价、查看进度和单据 | 用“客户视图”覆盖 |
| 管理层 | 看完成单、贡献、SLA、异常与应收 | 用控制塔首页覆盖 |
| 司机 / 车队 | 接单、上传装货证据和 POD | 本轮仅展示状态，不单独设计司机端 |

## 3. v0.1 信息架构

1. **今日控制塔**：北极星、在途、待报价、异常、POD、应收；按优先级给出行动队列。
2. **询价与报价**：左侧原始聊天，右侧结构化字段与分段报价；低置信字段必须人工确认。
3. **运单中心**：订单列表、筛选、风险标签、九环节状态机、操作与审计记录。
4. **客户追踪页**：免登录 H5；只暴露客户需要知道的节点、ETA、负责人和单据。
5. **数据与复盘**：先展示最小 KPI，不在本轮做复杂 BI。

## 4. 演示主线

使用一票“光伏组件，40HQ，CIF 蒙巴萨 → Athi River EPZ”的样例订单：

1. 进入今日控制塔，看到该票“待确认报价”；
2. 打开询价，查看 AI 从微信消息提取的柜型、港口、门点、货值与资料状态；
3. 检查清关、税费、干线和附加费四段报价，确认 SLA 与 48 小时有效期；
4. 点击“人工确认并发送”，订单进入已报价状态；
5. 打开运单，查看从到港资料到 POD / 对账的九环节；
6. 切换到客户视图，验证客户只看到清晰进度，不看到内部毛利与风控备注。

## 5. 明确不做

- 不做开放货运撮合大厅；
- 不做原生 App；
- 不做真实支付、GPS、海关接口或 WhatsApp / 企业微信连接；
- 不在没有核数前固化税率、价格与利润数字；原型数据均标为演示；
- 不让 AI 绕过报价、派单、付款等人工权限。

## 6. 从原型到 MVP 的最短路径

### W1–W2：零开发跑单

- 报价单模板、运单台账、状态字典、POD 文件命名规则定版；
- Sigma 选 10–20 票真实订单影子运行；
- 每个状态变更保留时间、人、凭证和备注。

### W3–W6：控制塔 MVP

- 数据模型只建五个核心对象：客户、询价、报价、运单、凭证；
- 首批权限只设运营、财务、管理层；
- 上线免登录追踪链接与 PDF 报价 / 对账输出；
- AI 只负责字段提取、草拟报价、异常摘要，所有关键动作人工确认。

### 验收口径

- 真实完成运单至少 50 票进入系统；
- 每票有报价版本、九环节时间戳、POD 与贡献结果；
- 报价字段提取准确率达到 98%，但仍保持人工确认；
- 客户能在 30 秒内回答“货在哪里、预计何时到、缺什么资料”；
- 管理层能每天回答“今天最危险的三票是什么、谁负责、下一动作是什么”。

## 7. 下一轮必须用现场数据校准

- Sigma 实际接单字段与原始聊天样本；
- 九环节真实名称、责任人和常见异常；
- 报价分段、最低可持续价与审批阈值；
- 客户可见 / 内部可见字段边界；
- POD、海关税单、CoC、提单等文件样例；
- 手机端网络条件、司机使用习惯与语言需求。

## 8. Sigma 模拟数据口径（2026-08-07 更新）

原型已接入 `Sigma业务数据_陈德雷_2026-08.xlsx` 和 `Sigma业务数据盘点表.xlsx` 的首轮粗数。为避免把待核数据呈现成事实，采用三层标识：

| 层级 | 原型中的数据 | 处理规则 |
|---|---|---|
| 已有粗数 | 月柜量 1,020、月票数 150、12 月累计 4,386、加权客单约 $2,357、海空 75%/25%、8 家车队 585+ 辆 | 可用于规模和分布模拟，但保留“待现场核数”提示 |
| 可倒算但不可定性 | 1,020 / 150 = 6.8 柜/票；$2,100 总价减 $1,311 干线采购价 = $789 | 展示计算关系，不把差额命名为收入、毛利或清关费 |
| 完全模拟 | 单票编号、客户聊天、运单状态、异常、ETA、SLA、负责人、POD 时点 | 统一使用 `SIM` 编号并明确标识，不进入经营口径 |

客户采用匿名映射：EPZ 光伏客户 A/B/C、建筑客户 D 等；只保留真实的 45% / 30% / 其余客户份额分布。报价样例采用 Sigma 已提供的头部框架价 `$2,100/柜` 与 Mombasa→Athi River 采购价 `$1,311`，税费不进入模拟总价。

## 9. 客户前端 Demo（2026-08-07）

客户前端由两个相互连接的触点组成：

1. **WhatsApp 客户助手**：自然语言查单、查询缺失资料、获取 ETA、转人工；AI 只解释和查询，不执行改单、费用确认或付款。
2. **手机 H5 订单中心**：查看订单列表和单票详情，包括运输进度、下一动作、单据、费用摘要与专属运营入口。

Demo 共用 `AFA-SIM-017 / 061 / 074 / 088` 四条匿名模拟订单。WhatsApp 订单卡片可进入 H5 单票详情，H5 可返回 WhatsApp 咨询，形成“聊天是入口、H5 是交易与凭证界面”的产品闭环。
