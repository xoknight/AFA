# 全链条商业模式与 Sigma 融合路线

> 依据：2026-08-05 董事会（平台定位升级为综合物流全链条）+ [肯尼亚贸易术语与全链条业务研究](肯尼亚贸易术语与全链条业务研究.md)，梁嘉文批准，2026-08-06 定稿。
> 本文含内部战略（§四第 3 层、§五），对外材料（官网/BP）仅使用「对外表述」栏目的措辞。

## 一、模式一句话：贸易条款升级器

中国供应商普遍只报 FOB/CIF——货主拿到的是「半截子物流」，货到蒙巴萨后的黑箱段（换单、清关、缴税、提柜、干线）无人兜底。**AFA 的生意 = 把货主手里的 FOB/CIF 升级成我们的合规 DDP**：从货主现有条款的断点起接管，一个责任窗口、一口价到门。

### 责任爬坡模型（收入随责任层级上移）
| 层级 | 接管范围 | 新增收入池 | 依托 | 状态 |
|---|---|---|---|---|
| **L1 · CIF 到港接管** | 换单+清关+缴税+干线 | 清关服务费 + 干线价差 | Sigma 现有主业务 | **今天就有** |
| **L2 · FOB 接管** | + 海运订舱 + 保险 | 订舱佣金 + 保险佣金 | Sigma 船司关系 + 股东资源 | 90 天内 |
| **L3 · 合规 DDP 全链** | + 中国揽货报关 + 含税到门 | 全链价差 + 代缴税费资金服务 | 中国揽货端伙伴（待建） | M6+ |
| **L4 · EAC 跨境** | + 过境乌干达/坦桑（SCT） | 跨境干线价差 | 阶段二 | M12+ |

空运（JKIA，2–3 天清关、高货值高毛利、Sigma 占比 25%）与海运并列双通道，四个层级均适用。

## 二、定价策略：确定性溢价，永不打价格战

市面「双清包税」低价 = 偷落地税负（约 CIF 的 50%：关税 0/10/25/35% + IDF 2.5% + RDL 2% + VAT 16%），代价是扣柜、罚款超货值、进口商上黑名单。**我们卖确定性：真实申报 + 持牌清关 + CoC/原产地证预检 + 全程数字跟踪**。灰色玩家每被查一次，都是在替我们做市场教育。与「不打价格战」纪律及资金合规红线完全自洽。

## 三、Sigma 融合：三段式演进，账在台面上

董事会口径：前期 Sigma 无条件扶持飞快达，后期利润回补；两主体股东不完全重叠，账必须清楚（陈小强，2026-08-05）。

| 阶段 | Sigma 角色 | 交易结构 | 目的 |
|---|---|---|---|
| **阶段 0（现在–M6）** | 发动机 | Sigma 全量订单走平台系统（左手倒右手也走系统）；平台收象征性系统服务费或记账不结算 | 跑出真实交易数据、打磨报价引擎；记账即「回补」凭据 |
| **阶段 1（M6–M18）** | 履约商 | 平台直接获客、对货主签全链条合同、按整单确认收入；清关分包 Sigma，按公允价结算 | 平台收入独立成立；Sigma 牌照/关务/口岸现场成为平台租用的资产 |
| **阶段 2（M18+）** | 首选供应商之一 | 海关接口 + AI 清关开放第三方清关公司（接口费/SaaS） | 平台中立化——估值故事从物流公司跳到平台 |

**治理配套（第一天就做）**：关联交易价目表（清关每柜、干线每公里），董事会批准、定期复核——美股审计第一个盯的就是 Sigma×AFA 关联交易，现在留底三年后省大钱。计费模型于 8/15 梁嘉文-陈小强面谈时确定。

## 四、护城河：咽喉的三层含义

1. **业务咽喉**（已有）：Sigma 牌照 + 关务团队 + 口岸现场；
2. **数据咽喉**（正在建）：HS 归类、税费测算、时效与卡点数据——AI 报价引擎的燃料；
3. **接口咽喉**（内部战略，不外发）：iCMS/KenTrade 对接深度 → 海关系统接口运营权 → 东非五国复制。运费可以被补贴，海关接口补贴不出来。

对外表述仅限第 1、2 层 +「与海关等监管系统深度对接的数字化能力」。

## 五、两个必须正视的风险（内部）

1. **DDP 资金重量**：一口价含税 → 每柜过手资金约一半是税费。设计为「**货主预付、平台代缴**」而非平台垫付——预付模式下先收钱后缴税，是负营运资金优势；垫付需求走轨道三持牌资金方。写入 BP 资金结构页。
2. **关联交易与利益冲突**：前期 Sigma 导流对其非重叠股东是让利，靠 §三 的记账回补机制 + 价目表化解；8/15 面谈定案。

## 六、90 天落地顺序

1. **周内**：BP/官网模式页升级为「全条款履约 + 海空双通道」表述（不依赖核数）；
2. **8/15 后**：定关联交易计费模型；L1（CIF 到港接管包）产品化，Sigma 订单走系统；
3. **30 天**：免费税费计算器 + 「无坑问答」会员上线（获客漏斗顶部 + 投资人可见的「产品已上线」）；
4. **60–90 天**：报价引擎 MVP（条款 × HS 档 × 税费栈自动测算），跑出首批「已完成、已取证、贡献为正」的平台运单——衔接深水区融资对真实交易数据的要求。
