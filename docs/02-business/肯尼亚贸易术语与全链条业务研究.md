# 肯尼亚场景下的 CIF / FOB / DDP / DAP 业务研究

> 依据：2026-08-05 董事会决定（平台定位升级为综合物流全链条），2026-08-05 整理。用于指导平台产品设计、官网与 BP 的定位表述。数据来源见文末；税率等以 iCMS 实际核算与肯尼亚律师确认为准。

## 一、四个贸易术语是什么（Incoterms 2020）

贸易术语回答一个问题：**从中国工厂到肯尼亚客户手里，每一段的钱谁付、风险谁担、清关谁办**。

| 术语 | 卖方（中国供应商）管到哪 | 买方（肯尼亚货主）从哪接手 | 适用运输方式 |
|---|---|---|---|
| **FOB** 离岸价 | 货装上起运港船舷为止（出口报关+装船） | 海运费、保险、目的港卸货、清关、缴税、内陆运输全部自理 | 仅海运 |
| **CIF** 到岸价 | FOB + 海运费 + 保险，到蒙巴萨港为止（风险其实在装船时已转移） | 到港后的换单、清关、缴税、干线运输 | 仅海运 |
| **DAP** 目的地交货 | 运到约定地点（如内罗毕仓库）待卸货，**不含进口清关和税** | 进口清关、关税、增值税由买方办理承担 | 任意方式（含空运） |
| **DDP** 完税后交货 | 全链条：出口报关+运输+进口清关+**缴清所有税费**+送到门 | 只需收货 | 任意方式（含空运） |

关键梯度：**FOB → CIF → DAP → DDP，卖方责任逐级加重；DDP 是「一口价全包」的极致形态**。谁承接的环节多，谁赚的服务价差就多——这正是平台要吃下的空间。

## 二、中肯贸易的现实玩法与市场痛点

1. **中国供应商普遍只报 FOB / CIF**：意味着货一到蒙巴萨，清关、缴税、提柜、干线这一整段（最容易踩坑、最不透明的一段）全部甩给肯尼亚买方——这正是 Sigma/AFA 的主场。
2. **市场上流行「双清包税」（类 DDP 专线）**：货代以自己名义统一报关清关、一口价含税。灰色玩法集中在：**低申报货值、错报 HS code、借用他人税号清关**；后果是货物扣押没收、罚款超货值、进口商被标记为高风险。中国到肯尼亚 DDP 专线大量存在此类操作。
3. **踩坑率极高**（董事会陈德雷判断一致）：清关知识盲区大、无 CoC 到港、低价包税被查扣——这是「无坑问答」引流产品和「合规 DDP」差异化定位的现实土壤。

## 三、肯尼亚进口合规链（做 DDP 必须吃透的每一环）

### 3.1 单证与系统
- **IDF 进口申报单**：货到港前经 **iCMS** 电子预申报；IDF 费为 **CIF 值的 2.5%**（Finance Act 2023 从 3.5% 下调）。
- **iCMS（KRA 海关综合管理系统）** + **KenTrade TradeNet 单一窗口**：清关代理电子递交报关单，联动 KEBS、药监等多部门审批——这就是董事会说的「海关接口」所在层。
- **CoC 符合性证书（KEBS PVoC）**：受管制商品在中国出口前须由 **Cotecna / Intertek** 验货发证；**无 CoC 到港 = 目的地检验（缴核定货值 0.6% 检验费）+ 滞留风险**；有 CoC 直接放行。
- **原产地证书**：2025 年 10 月 1 日起全面强制执行，所有进港货物必须随附出口国权威机构签发的原产地证。
- **持牌清关代理**：进口必须通过 KRA 持牌代理（C20 申请/C21 牌照，年费 $400 + iCMS 接入费 KSh 15,000）——Sigma 的牌照与代理能力是平台做 DDP 的合规底座。

### 3.2 税费栈（DDP 报价引擎的核心公式）
| 税费 | 税率 | 计税基数 |
|---|---|---|
| 关税 Import Duty | **0% / 10% / 25% / 35%**（EAC 共同对外关税四档：原材料与资本品 / 中间品 / 制成品 / 敏感品） | CIF 值 |
| 消费税 Excise | 视品类 | CIF + 关税 |
| IDF 费 | **2.5%** | CIF 值 |
| 铁路发展捐 RDL | **2%**（2024 年 12 月从 1.5% 上调） | CIF 值 |
| 增值税 VAT | **16%** | CIF + 关税 + 消费税（部分口径含 IDF/RDL，以 iCMS 实际核算为准） |

**示例**（$10,000 CIF 制成品，25% 档，无消费税）：关税 $2,500 + IDF $250 + RDL $200 + VAT ≈ $2,000–2,072 ≈ **落地税负约 50%**。做 DDP 一口价，这套测算必须自动化、精准化——低申报省下的就是这 50%，也正是灰色玩家的「价格优势」和被查扣的根源。

### 3.3 空运（JKIA）
- 流程同走 iCMS（IDF、舱单、空运申报），货存航司货站（如肯航货站）。
- **时效显著优于海运**：标准货当天核定、小票货次日可提；持牌代理可把平均清关时间从 5 天压到 2–3 天。
- 高货值、高时效货的通道，**利润率高于海运**（董事会陈小强强调）——平台必须覆盖。

### 3.4 过境/转口（东非五国）
- **EAC 单一关境（SCT）**：蒙巴萨到乌干达/卢旺达等过境货免重复报关，**过境乌干达不需要 IDF**；一站式边境口岸（OSBP）大幅缩短过境时间。
- 蒙巴萨过境货 65.7% 目的地为乌干达——「大陆→蒙巴萨→坎帕拉」的全程 DAP/DDP 报价是天然的跨境延伸产品。

## 四、对 AFA 平台的业务设计启示

### 4.1 产品分层：按术语切服务包
| 货主手里的条款 | 痛点 | AFA 服务包 |
|---|---|---|
| 供应商报 FOB | 海运订舱、保险、清关、干线全要自己拼 | **FOB 接管包**：订舱+保险+清关+干线一口价 |
| 供应商报 CIF | 到港后清关缴税提柜是黑箱 | **到港接管包**：换单+清关+缴税+干线（Sigma 现有主业务的产品化） |
| 想要 DAP/DDP | 市面全包=灰色包税，风险大 | **合规 DDP 全链条**：中国揽货端联动，真实申报、一口价含税到门 |
| 出口/转口东非 | EAC 过境规则不熟 | **跨境过境包**：SCT 过境、保税、蒙巴萨→坎帕拉全程 |

### 4.2 定位与差异化
- **卖「确定性」而非「低价」**：与灰色双清包税正面差异化——我们的 DDP 是真实申报+持牌清关（Sigma）+全程数字跟踪；客户买的是「不被扣柜、不被罚款、时效可预期」。与仓库红线（不做非合规通道）和「责任型 3PL」口径完全一致。
- **AI 的用武之地**：HS code 归类与税档判断、CIF 税费自动测算、CoC/原产地证预检清单、iCMS 状态跟踪——每一项都是现在靠人肉和经验、踩坑率极高的环节。
- **引流闭环**：免费税费计算器 + 「无坑问答」会员（$99.9 级）→ 清关订单 → 干线运输 → 全链条 DDP。

### 4.3 报价引擎必备字段
起运地/目的地、海运/空运、贸易术语、HS code（→关税档）、CIF 货值、CoC 状态、是否过境（EAC SCT）→ 输出：分段明细价 + 一口价（含税/不含税双口径）。

### 4.4 对外表述（官网/BP 用语）
- 「覆盖 FOB / CIF / DAP / DDP 全条款履约：从中国工厂到东非门点，一个责任窗口、一口价到门」
- 「合规完税的 DDP——不做低申报，确定性就是品牌」
- 空运与海运并列为双通道（Sigma 空运占比 25%、JKIA 2–3 天清关时效可作数据点）
