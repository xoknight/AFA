# 商业模式：责任型数字 3PL

> 2026-08-06 升级：定位扩展为综合物流全链条（FOB/CIF/DAP/DDP 全条款履约、海空双通道），责任爬坡模型与 Sigma 融合三段式见 [全链条商业模式与Sigma融合](全链条商业模式与Sigma融合.md)。

## 一句话
不做"菜市场"（开放货源大厅），做"山姆会员店"——两端筛选、平台担责、确定性即品牌。信息平台对信息负责，我们对全流程结果负责。**无论货主的供应商报 FOB/CIF/DAP/DDP 哪种条款，从那一段起我们接管到门。**

## 与开放撮合的差异
| 维度 | 开放撮合（上一批玩家） | 非快达 |
|---|---|---|
| 交易结构 | 货主自发布、司机抢单竞价 | 平台受控报价、指派认证承运人、对结果担责 |
| 价格 | 最低价竞拍 | 参考价 + 最低可持续价 + 燃油/等待附加费 |
| 收入 | 佣金/广告 | 运输服务价差/贡献毛利，后期叠加会员费与 SaaS |
| 现金 | 号称轻资产实则垫资黑洞 | 重营运资金：预充值 + 授信 + 持牌资金方 |

## 收入结构（清关引流 → 全链赚钱 → 平台增值）
1. 清关及关务服务（现有主要利润来源，高毛利，咽喉环节）
2. 干线运输与海空运输服务价差（单票贡献率目标 8%→15%；空运高毛利通道，Sigma 占比 25%）
3. 全链条 DDP 增量：海运订舱与保险佣金、中国揽货端联动、代缴税费资金服务（货主预付、平台代缴）
4. 会员费（含「无坑问答」清关知识会员）+ 控制塔 SaaS 输出（规模化后）

## 一单到底九环节
获客信用 → 询价报价 → 订单确认 → 找车派单 → 装货发车 → 在途异常 → 卸货签收 → 对账结算 → 复盘学习。异常是独立业务对象（类型/时间位置/责任方/证据/影响/owner/升级/SLA/赔付/根因），全部回流定价与派单规则。

## 产品边界
- **自建**：交易内核（客户/报价/订单/调度/运单/异常/结算/利润规则）、承运评分与派单、参考价与附加费引擎、授信与停单、审计日志。
- **外采**：云/OCR/大模型、地图围栏 GPS、身份验证、M-PESA 与银行批付、eTIMS。
- **持牌方承担**：保险、支付清算、快付与订单融资、法律税务意见。
- **明确不做**：区块链存证、自研硬件、无数据自动定价、三个原生 App 同时上线（首期 WhatsApp/PWA + 司机轻端）。

## 运力组织
核心签约车队 50% + 认证 owner-operators 35% + 备用池 15%。评分五维：文件合规/可用响应/履约/质量/经济。三条铁律：不补贴临时运力、奖励只在首单合格后发、只展示资质有效运力。
