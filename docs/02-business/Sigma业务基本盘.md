# Sigma 业务基本盘

## 定位
Sigma = 肯尼亚最大清关公司（对外表述待数据核实），由陈小强、陈德雷在肯尼亚一线运营，覆盖空运、港口等清关物流全环节——切实抓住"清关"这个核心抓手。

## 核心数字（2026 基线，待审计锁定）
- 年业务流水 ≈ **$800 万**（拆分：运输 GMV $4.5M + 清关服务收入 $1.8M + 代收代垫 $1.7M）
- 会计口径营业收入 2026E ≈ **$6.3M**（全部预测基准）
- 利润 ≈ **$60 万**（H1，现金在账，零补贴）；2026 全年净利目标 $300 万
- 月发运 ≈ **1,000 标箱**；头部车队给到 **45 天账期**（行业信任凭证）

## 数据资产（护城河）
核心线路（蒙巴萨→内罗毕 A109 约 490km、JKIA 机场→内罗毕）：每公里油费、运输时长、沿线卡点清单、卡关处置方式——全部一线实测在手。

## 天使客户模式（Sigma × 飞快达）
1. Sigma 是飞快达**第一个天使客户**：整套传统业务全部数字化，平台首月即有真实订单、收入、数据；
2. 数据基座：订单、线路、价格、异常、账期全量沉淀，构成定价引擎与信用体系的种子数据；
3. 模式样板：跑通后覆盖其他货运平台、物流公司与清关公司；
4. 两主体经济与法律上独立、互为交易对手（合规要求）。
