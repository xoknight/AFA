## 0. 执行摘要

**一句话结论：非快达当前最大的瓶颈不是方向、不是资源，而是「平台尚无一单自己的运单数据」——战略已收敛（全链条 DDP + 确定性溢价），资源已到位（Sigma 基本盘 + 五人股东矩阵），从现在起一切工作向一个北极星收口：M1–M2 内跑出第一批「已完成、已取证、贡献为正」的平台运单。**

三个关键判断：
1. **先上系统再谈优化**：Sigma 订单全量走系统（左手倒右手也走）是数据地基，没有它，定价引擎、融资深水区、AI 数字员工全部悬空；
2. **融资与业务是同一件事的两面**：投资人卡点「要看到软件上线与真实交易数据」（沙利文场实证）与业务卡点完全重合——跑数据即是融资动作；
3. **人类决策节点不可省**：数字员工备料、董事会拍板；每周一次决策收口（现有周会）+ 每月复盘包（8/8 Sigma 月会并轨）。

## 1. 定位复盘（波特框架）

### 1.1 我们是一家什么样的公司
- **业务本质**：不是撮合信息平台，是**贸易条款升级器**——把货主手里的 FOB/CIF 半截子物流升级成合规 DDP 全链条，对每一单交付结果负责（责任型数字 3PL）；
- **核心资产**：Sigma 清关咽喉（牌照+现场+车队信任）× 实测数据（价格/时效/卡点）× AI 原生组织（数字员工矩阵）；
- **单一品牌**：非快达 / AFRICA FAST ARRIVAL——「非洲快速达到」。

### 1.2 三大通用战略适配
| 通用战略 | 适配度 | 判断 |
|---|---|---|
| 成本领先 | 低——灰色包税玩家永远比我们「便宜」，跟进即死（Sendy 教训） | 明确放弃 |
| 差异化 | 高——确定性溢价：SLA + 合规完税 + 全程数字跟踪，行业通病（效率低、人不见、踩坑多）反衬 | ★ 主战略 |
| 聚焦利基 | 高——蒙内走廊 × 中资 EPZ/贸易客群，单走廊打透再扩 | ★ 切入战略 |

### 1.3 五力速览
- **新进入者**：运满满式平台若入场，可补贴运费但补不出清关咽喉与海关接口——护城河建在「垂直 know-how + 监管对接 + 数据飞轮」而非 App；15 小时航程与本地化门槛本身是屏障；
- **替代品**：传统货代/清关行（关系强、数字化弱）+ 灰色双清专线（低价、高风险）——我们吃「被灰色玩家坑过的客户」与「要审计合规的中大型货主」；
- **客户议价力**：高（前两大客户占 75%）——**这是当前最锋利的战略风险**，12 个月内降到 ≤50%；
- **供给议价力**：中——585+ 辆多车队结构 + 账期在我方，用稳定货源与快付换忠诚；
- **现有竞争**：Lori 低谷、Leta 偏 SaaS、大出清后真空——窗口期约 18 个月（2027 大选前）。

## 5. 非快达决策飞轮

### 5.1 大循环
**战略校准 → 融资推进 → 产品与运单 → 运营数据沉淀 → 财务盘点 →（回到）战略校准**

### 5.2 五个小循环
| 循环 | 输入 | 输出 | 责任人 + 数字员工 | 人类决策节点 | 沉淀位置 |
|---|---|---|---|---|---|
| ① 融资循环 | 路演反馈、TS 进展 | 意向漏斗、话术迭代、BP 修订 | 朱学峰 + 融资跟进数字员工 | 周会（五人） | 融资跟进台账 |
| ② 客户与运单循环 | 平台运单、客户反馈 | 定价校准、转化率、PMF 证据 | Gavin/陈德雷 + 运营数字员工 | Gavin 周度 | 运单系统 + 客户反馈台账 |
| ③ 竞品与市场循环 | 竞品动态、政策变化 | 月度情报简报 | 数字员工（月度扫描） | 月度会 | 竞品情报台账 |
| ④ 产品循环 | 反馈 + 运营卡点 | MVP 迭代优先级 | Gavin + 开发数字员工 | Gavin 排期 | GitHub issue |
| ⑤ 组织与财务循环 | 编制执行、烧钱、13 周现金 | 预算校准、扩编决策 | 程志斌 + 财务数字员工 | 董事会月度 | 经营模型与预算盘点 |
