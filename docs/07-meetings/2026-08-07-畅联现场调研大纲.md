## 一、重点调研什么：按「我们 90 天必须做的五个决定」倒推

不做泛泛学习。每一块调研直接对应我们一个悬而未决的决定。

### 决定 A · TMS / 交易内核 MVP 先建哪几个模块（最高优先级）
**我们的处境**：平台运单 0 单，90 天 MVP，2 人技术 + AI 数字员工（假设 H6 未验证）。建错顺序 = 亏掉整个窗口期。

必问：
1. 如果今天重来一遍，**第一个建的模块是什么？第二个？** 哪个模块当时觉得重要、后来发现没用？
2. 你们的**订单主数据长什么样**——一张运单上有多少必填字段？异常是不是独立对象？（能要到数据字典最好，要不到就现场看一眼界面截图级别的东西）
3. 报价、派单、结算三者哪个先自动化？哪个至今坚决不自动化？
4. 从纸/Excel 迁到系统时，**司机端和客户端谁最难推？**怎么推动的？

**为什么问这个**：我们的 [产品形态与定价体系](../02-business/产品形态与定价体系.md) 定了「系统在后台、客户在聊天里」，第 1 周就要用微信群数字员工跑 S1——他们的推行阻力经验直接决定我们要不要坚持不做 App。

### 决定 B · 责任型（principal）身份的法律、税务与保险配置
**我们的处境**：全链条 DDP + 责任爬坡 L1–L4 已定稿，但**「对结果负责」在合同里到底怎么写、赔到什么程度**我们没有范本；肯尼亚有 Sendy 税案前车之鉴。

必问：
5. 「信息平台对信息负责、我们对结果负责」——这句话在合同里的**索赔上限、免责边界、保险配比**是怎么写的？出过最大一笔赔付是多少、怎么定责的？
6. 责任身份下**收入按全额还是净额确认**？开票链路怎么设计？（这条直接决定我们的估值叙事口径，也决定 8/15 之后关联交易价目表怎么定）
7. 有没有哪类货、哪类客户你们**主动退回撮合/代理模式**？为什么退？——**这是今天最值钱的问题之一**：知道边界在哪，比知道能做什么更有用。

### 决定 C · 单位经济守不守得住 + 垫资资金结构
**我们的处境**：内部模型按**单票贡献率 8%→15%**、月 440 单打平；营运资金轨道 $300–500 万独立于股权轨道，但**规模依据来自 DSO−DPO 的估算，未被外部验证过**。

必问：
8. 一单的贡献毛利结构：承运采购占多少？保险/索赔准备金按什么比例提？**低于多少贡献率坚决拒接**？
9. 客户账期 vs 承运人付款的资金缺口，用什么钱填？成本多少？坏账率多少？**垫资出过大事故吗**？
10. 净利率个位数、低毛利强周转——**靠什么活过价格战**？哪一年最难、怎么过来的？

### 决定 D · 运力组织：注册数 ≠ 可用数
**我们的处境**：对外用「585+ 可调度车辆」，但真实可用运力的**测量口径我们自己都没定义**；核心签约 50% / 认证个体 35% / 备用 15% 的结构是设计值不是实测值。

必问：
11. 「注册车辆数」和「某线路某时段真实可用车」差几倍？你们内部用什么指标管这件事？
12. 承运人取消率多少？临时放鸽子怎么兜？备用车池怎么养（养着不用要不要给钱）？
13. 派单渠道真实占比：熟司机池 / 同行伙伴 / 自有 App / 外采平台 各多少？

### 决定 E · AI 落地的真实水位（挤水分）
**我们的处境**：整套组织设计押在「AI 数字员工矩阵」上（H6：2 人 + AI 交付 MVP）。我们需要一个已经做了几年 AI 的同行告诉我们**哪里是真的、哪里是 PPT**。

必问：
14. 五类 AI 能力（知识助手 / 需求转单 / 报价 / 调度 / 订单管理）**真实生产渗透率各是多少？人工修改率多少**？
15. 哪个 AI 的 ROI 最高？哪个投了钱没用起来？
16. 「AI 录单 100% 准确」的**测量口径**是什么？有没有因 AI 错单赔过钱？
17. 每月 AI 成本量级、选了哪家模型、为什么？

### 决定 F（收尾，视气氛）· 伙伴分润与合作可能
18. 销售返佣档位怎么定？**反串单 / 私收款 / 关联车队怎么发现和治理**——踩过什么坑？（我们的返佣策略 v1 刚出，五条红线还没被现实检验）
19. 2027 年「数字员工对外输出」的规划——**肯尼亚愿不愿意做第一个海外试验场**？形式可以是系统授权、联合运营或顾问。
20. （朱学峰把握时机）对非洲物流这个赛道，您个人怎么看？有没有兴趣以某种方式参与进来？——**只探态度，不谈结构**。

## 二、需要诚恳请教的 vs 需要核实的（两种问法，不要混）

### 请教型（姿态低，问「你怎么做的」）
- 二十年里**最贵的一个错误**是什么？——这个问题一定要问，而且要留足沉默让对方说完；
- 从项目物流转数字 3PL，**老团队怎么转过来的？流失过客户吗**？（我们要把 Sigma 的线下团队搬上平台，一模一样的坎）
- 哪个环节**坚决不该自动化**？
- 数字化最先建的那个系统，如果重来会不会换？

### 核实型（拿我们自己的假设去撞，问「这个数在你们那儿是多少」）
| 我们的〔假设〕 | 出处 | 向畅联核实的问法 |
|---|---|---|
| 单票贡献率 8%→15% | 经营模型 v1 | 「我们按 8% 做打平模型，在您那儿这个数现实吗？中国干线的真实区间是多少？」 |
| 月 440 单打平 | 经营模型 v1 | 「您起步阶段的盈亏平衡单量是多少？固定成本主要压在哪？」 |
| 客户愿为确定性付 8–15% 溢价（H3） | 战略假设台账 | 「确定性到底能不能卖出溢价？您的客户为 SLA 多付过钱吗？」 |
| 回程配载 +10pp = 纯增量毛利（H2） | 战略假设台账 | 「回程空驶你们压到多少？用什么办法压的？」 |
| 585+ 可调度车辆 | 官网/BP | 「可用运力你们怎么定义和统计？」 |
| 2 人 + AI 可交付 MVP（H6） | 战略假设台账 | 「你们那套系统当时几个人做的？做了多久？」 |
| 账期费用 1%/2%/3% 计入报价 | 畅联公开资料 | 「这个客户接受度真实如何？有没有被要求砍掉？」 |

**核实纪律**：拿回来的每个数字，标注「畅联口径·中国市场」入库，**不得直接替换我们的肯尼亚假设**——只作为量级参照与合理性判断依据。

### 求证型（侧面，不追问）
- 「听说满帮在看海外市场，您有听到什么动向吗？」——一句话带过，对方接就听，不接就换话题。（内部按待证实情报处理，不写入对外材料）

## 三、要避开的坑

### 坑 1 · 姿态坑：把「学习」做成「同行探底」或「给人上课」
- 我们有非洲的稀缺信息，容易讲嗨。**记住比例：讲 30%、听 70%**。给市场量级和差异化思路，不给我们的具体经营数据；
- 不要评论对方的模式好坏，不要说「我们准备怎么怎么超过这个」；
- 对方讲经验时不要急着接「我们也是这样」——那句话一说出口，后面的细节就不给你了。

### 坑 2 · 数据坑：把中国参数直接搬到肯尼亚
中国和肯尼亚在这些维度**不可平移**，听到任何数字先在心里打上标签：
- **密度**：中国干线密度支撑的匹配率、回程配载率，肯尼亚做不到；
- **征信与执行**：司机/承运人的违约成本、法律执行效率完全不同；
- **成本结构**：油价、路况、过路费、司机工资、车辆折旧；
- **金融基础设施**：账期、保理、快付在中国有成熟基础设施，肯尼亚要用 M-PESA/银行批付重做；
- **监管**：KRA/eTIMS/预申报新规 vs 中国税务；外汇管制（这条还叠加我们的资金合规红线）。

### 坑 3 · 幸存者偏差：把「二十年后的结果」当「起步蓝图」
他们今天的组织、系统、分润结构是**规模之后的产物**。真正对我们有用的是**他们第 1–3 年怎么活的**。所以每个问题都要追一句：**「这个是你们什么时候开始这么做的？之前是怎么做的？」**

### 坑 4 · 合作坑：把「看合作」做成「空口谈合作」
- 董事会口径是「看合作（投资入股）机会」，**看** ≠ 谈。今天只做三件事：表达兴趣、了解对方决策方式、约下一次；
- 不给排他、不给时间表、不透露融资条款与估值；
- 如果对方主动问「你们融多少、什么估值」——标准答复：「种子轮在推进中，条款还在和董事会敲，等我 8/15 从内罗毕核完数，把完整材料正式发您」。**用 8/15 核数当挡箭牌，既真实又体面**。

### 坑 5 · 我方口径坑：说了未锁定的数字
Sigma 柜量（1000+柜 vs 在库 4,386）、利润（$58–62 万）、正式运营时间——**三项互相冲突且 8/15 才锁**。今天一律用定性表述：「当地头部清关商，年化规模千万美金量级」。**宁可说少，不可说错**——今天说出去的数，8/15 之后可能要改口。

### 坑 6 · 细节坑：名字与主体
进门前确认对方的**准确公司全称与主体关系**（畅联 / 联畅、联畅云与联畅运是同一主体还是关联公司）。我们仓库里两种写法都出现过，会上叫错名是最不该犯的错。名片当场核对，会后按准确全称回写文档。

## 六、Sigma 速答卡（被问到我们的数据时照着答）

> 数据源：[Sigma 业务数据台账](../02-business/Sigma业务数据台账.md)（陈德雷 2026-08 首轮实测）、[Sigma 模式分析与定价返佣策略](../02-business/Sigma模式分析与定价返佣策略.md)、[数据口径字典](../04-operations/数据口径字典.md)。
> **今天的总原则：讲结构、讲案例、讲比例，不讲绝对值。** 8/15 才现场核数，8/5 董事会已确认此前表格多处有误（累计柜量「1000+柜+300 托」与在库 4,386 柜冲突、利润 $58–62 万逐项复核中）——今天说出去的任何精确数字，两周后都可能要改口。**对一个做了二十年物流的人，一个真实案例的说服力远大于一张没审计的报表。**

### 6.1 可以放心说的（结构性事实，核数不会推翻）

| 维度 | 今天可用的说法 |
|---|---|
| **起步与速度** | 清关业务 **2025 年 9 月上线**，一年内做到**月柜量四位数**——从月三十几柜起步 |
| **客户结构** | 活跃客户 **8 家**；**4 家 EPZ 出口加工区光伏企业占柜量约 89%**，1 家建筑项目企业；中资背景为主 |
| **货值量级**（≠流水≠收入，务必说清） | 光伏电池片 40ft 柜单柜货值约 **$132 万**、组件柜约 **$100 万**、建材护栏柜约 **$5.5 万**——**一柜货值是运费的数百倍** |
| **通道结构** | 海运约 **75%** / 空运约 **25%**（蒙巴萨港 + JKIA 机场双通道） |
| **运力组织** | **8 家合作车队全外部**，账期 **14–45 天**在我方；不自有车 |
| **线路实测** | 蒙巴萨→内罗毕 A109 约 **490 km**，单程平均 **14 小时**；重卡重去空回油耗 **110 KES/km**；**回程配载率仅 5%** |
| **客户黏性** | 复购率约 **95%**（口径：老客户持续下单比例，非合同续约率——被追问就这么说） |
| **平台侧** | **诚实说 0 单**。平台 MVP 90 天内上线，Sigma 订单全量走系统是第一步——**这正是我今天来求教的原因** |

### 6.2 五个运营能力与优势（讲案例，不讲形容词）

| 优势 | 现场怎么讲 | 本质（讲完可以点一句） |
|---|---|---|
| **危机处置力** ★最强 | 「有一批 **100 个货柜**被其他代理滞留在港口 **4–6 个月**，我们接手后**一周解决**，替客户挽回百万美金级损失。」 | 口岸现场能力 + 关务关系——买不来、抄不走 |
| **高货值信任** | 「客户把单柜 130 万美金的电池片长期交给我们。」 | 高货值客户换服务商的转换成本极高，这是信任壁垒不是价格壁垒 |
| **响应与效率** | 「当地同行的通病是效率低、价格高、动不动人找不到；我们是**凌晨两点找得到人**。」（陈小强对比 30+ 家同行的结论） | 行业的短板恰是我们的长板——**确定性** |
| **供给侧信用** | 「8 家车队给我们 14–45 天账期、几百辆车随调——新玩家在肯尼亚拿不到账期。」 | 账期就是行业对我们的信任凭证 |
| **全环节覆盖** | 「港口和机场双通道、清关到干线一口价，客户需求不外溢。」 | 一站式 = 咽喉位置 |

**一句话总结（可以直接用）**：**Sigma 赢在「确定性」不在价格——这也是非快达敢做确定性溢价定价的实证基础。**

### 6.3 对方大概率会问的八个问题 + 标准答法

| 他问 | 你答 |
|---|---|
| **一年做多少量 / 多少流水？** | 「**千万美金流水量级**，月柜量四位数。精确口径我们 8/15 在内罗毕现场核数，核完把完整材料正式发您。」——**流水不等于收入，主动说清楚，这一点会让内行对你加分** |
| **赚钱吗？毛利多少？** | 「盈利，现金在账、**零补贴**。结构可以讲：清关+干线一口价里，**承运采购占五到六成**，剩下的是清关服务与毛利空间。具体数字等核完数。」——**给比例不给绝对值**，既能被对方校验（这正是我们要的决定 C 外部验证），又不泄露客户单价 |
| **客户是谁？** | 不给名单，给画像：「EPZ 出口加工区的中资光伏企业为主，加建筑项目客户。这类客户**对确定性极度敏感、对价格相对不敏感**——一柜货值是运费的几百倍，晚一天的损失远超运费差价。」 |
| **车是自己的吗？** | 「一辆不自有，8 家车队全外部，靠稳定货源和账期绑定。」——**和他们的模式同构，这是最容易聊深的一个点，可顺势转到「决定 D」提问** |
| **平台跑了多少单？** | 「**一单没有。**」——**必须诚实**。接一句：「所以我今天最想请教的是：您当年从零开始，第一个模块建的是什么。」诚实 + 求教，是今天最好的姿态 |
| **客户集中度？** | **主动交底**：「前两大客户占 75%，这是我们目前最锋利的风险，12 个月内要压到 50% 以下——平台化接非 EPZ 和小客户正是为这个。」主动说短板比被问出来强十倍 |
| **竞争对手？** | 「上一批开放撮合玩家大出清（Lori 收缩、Sendy 出事、Kobo360/Amitruck 退场），留下真空；现在主要对手是传统货代和灰色双清专线——**灰色玩家每被查一次，都在替我们做市场教育。**」 |
| **你们融多少、什么估值？** | 「种子轮在推进，条款还在和董事会敲。等我 8/15 从内罗毕核完数，把完整材料正式发您。」——**用核数当挡箭牌，真实且体面** |

### 6.4 今天不说的数字（说了 8/15 之后要改口）

| 不说 | 原因 |
|---|---|
| 累计柜量（4,386 柜 / 1000+柜+300 托） | **两个口径互相冲突**，8/15 才锁 |
| 利润金额（$58–62 万 / $60 万） | 董事会已明确「此前表格多处有误，逐项检查中」 |
| 客单价（$2,100 / $2,357 / $3,300） | ① 是否含代收代垫税费未厘清（决定收入是全额还是净额确认）；② 属客户敏感信息 |
| 年流水精确数（$800 万 / $1,000 万 / 年化 $3,000 万） | 累计口径与 run-rate 口径并存，不注明就是误导——**只说「千万美金量级」** |
| 「肯尼亚最大清关公司」 | 可引用依据未取证，一律改说**「当地头部清关商」** |
| 会计营业收入 $6.3M | 预测值，基线报表 9 月中才出 |
| 具体客户名称、车队名称 | 商业敏感 |
| 2027 年月 5000 柜 / 月流水 $1000 万 | 可行性分析原稿未入库，对外说 = 吹牛风险 |

### 6.5 我们自己心里要有数的短板（对方一眼看得出，别装）

1. **客户集中度**前两大 75%；2. **回程配载仅 5%**（也是我们最大的确定性增量空间，可以作为亮点讲）；3. **无系统、数据未沉淀**（Sigma 至今靠人和 Excel——所以才有非快达）；4. **关键人依赖**（陈德雷一人扛肯尼亚一线）；5. **口径未审计**（会计师基线报表 9 月中）。

被点到任何一条，答法统一：**「对，这正是我们要做平台的原因」**——把短板转成 why now。
