## 共同失败链路
货量密度不足 → 压价补贴换增长 → 单票毛利转负 → 货主 30–90 天回款 vs 车队即时要钱 → 依赖持续授信垫资 → 油价/大选/抽贷任一触发 → 资金链断裂。

## 六类风险机制 → 我们的设计约束（对赌口径基础）
1. 全国注册数 ≠ 单走廊流动性 → 密度按「线路×车型×时间窗」；北极星 = 每周已完成、已取证、贡献为正的运单数
2. 低价增长毁毛利 → 参考价 + 最低可持续价 + 附加费；低于阈值强制修价/降服务/退出
3. 账期错配 → 预充值 + 授信 + 逾期停单；快付由持牌资金方承担，不进平台资产负债表
4. "资产轻"≠"运营轻" → 每单人工介入次数列为 KPI；调度台与 24h 响应是产品的一部分
5. 未熟先扩 → 阶段闸门制
6. App 可用性 ≠ 商业闭环 → 只披露已完成、已取证、已回款口径

## 中国对标
- **满帮**：可复制认证、信息标准化、智能推荐、信用体系；不可复制建立在数百万密度上的开放竞价。我们复制其网络效应之前的"密度建设阶段"。
- **联畅**（南京，董事长耿卫军）：托管型 B2B 数字 3PL——对全流程结果负责、外部运力 + 统一 TMS + 伙伴分润；验证责任型模式可持续盈利二十年。2026-08-07 实地交流，见 [沟通纪要](../07-meetings/2026-08-07-联畅沟通纪要.md)。

### 联畅交流带回的三条外部验证（2026-08-07）

1. **满帮模式不可移植的根因是运力结构，不是技术**——耿卫军："**过剩才导致这个模式能推得下去**"。中国运力严重过剩、供给端是个体驾驶员（小 C），撮合与竞价才成立；肯尼亚**运力不足、供给端是车队（to B）**，开放竞价没有生存土壤。这是我们「不做菜市场做山姆」定位的最强外部论证。
2. **健康的运力结构 ≈ 七成长期合作 + 三成临时**：联畅临时找车比例**低于 30%**。可作为我们「核心签约 50% / 认证个体 35% / 备用 15%」设计值的外部参照。
3. **数字化从投入到见效约 2 年**：联畅 2022 年启动、2024 年后见效，今年增速 +35~40%（近两月 >50%），而行业总盘在下降。**"90 天出 MVP" 与 "两年见效" 不矛盾，但要在对投资人叙事时区分「上线」与「见效」。**

### 前车之鉴的现场版机理（补充 Sendy/Kobo360 的死法细节）

Gavin 现场复述的东非既往玩家（约 4 家同类软件）死亡链路，比公开资料更具体：

- **补贴链**：补贴司机 + 补贴货主 → 压低运价 → **损害车队利益** → 车队不给好运力 → 服务崩坏 → 闹翻；
- **油费垫资链（本地特有）**：当地油价高，**司机要求运完立即结油费**；而货主要"卖完货收到钱才付款" → 平台被夹在中间垫资 → 现金流断裂。
- **资金成本放大器**：肯尼亚本地融资/租赁利率约 **10–20%+**，"跟放贷一样"——垫资在这里比在中国致命得多，与 Kobo360（当地利率 20%+ 举债垫资）同源。
- → 直接强化设计约束第 3 条（账期错配）：**预充值 + 授信 + 逾期停单不是可选项，是生死线**；油费类刚性支出必须由货主预付或由持牌资金方承接，绝不进平台表内。
