| 平台 | 结局 | 规模 | 直接启示 |
|---|---|---|---|
| Sendy（肯尼亚） | 2023 停运、进入管理程序 | 融资约 $2,650 万；客户含 Unilever/DHL/Maersk | 峰期月烧 $100 万；好产品与大客户替代不了正贡献毛利；2025 高院税案：自称"平台"不免除实质控制的 VAT 责任 |

| Amitruck（肯尼亚） | 双端 App 下架 | 种子轮 $400 万；注册车 8,000 辆 | 开放最低价竞拍→逆向选择→两端不信任 |
| Convoy（美国） | 2023 关闭 | 曾估值 $38 亿、融资 $9.25 亿 | 最成熟市场同样失败——模式风险而非执行风险 |

## 共同失败链路
货量密度不足 → 压价补贴换增长 → 单票毛利转负 → 货主 30–90 天回款 vs 车队即时要钱 → 依赖持续授信垫资 → 油价/大选/抽贷任一触发 → 资金链断裂。

## 六类风险机制 → 我们的设计约束（对赌口径基础）
1. 全国注册数 ≠ 单走廊流动性 → 密度按「线路×车型×时间窗」；北极星 = 每周已完成、已取证、贡献为正的运单数
2. 低价增长毁毛利 → 参考价 + 最低可持续价 + 附加费；低于阈值强制修价/降服务/退出
3. 账期错配 → 预充值 + 授信 + 逾期停单；快付由持牌资金方承担，不进平台资产负债表
4. "资产轻"≠"运营轻" → 每单人工介入次数列为 KPI；调度台与 24h 响应是产品的一部分
5. 未熟先扩 → 阶段闸门制
6. App 可用性 ≠ 商业闭环 → 只披露已完成、已取证、已回款口径

## 中国对标
- **满帮**：可复制认证、信息标准化、智能推荐、信用体系；不可复制建立在数百万密度上的开放竞价。我们复制其网络效应之前的"密度建设阶段"。
- **联畅（畅联式运输组织）**：托管型 B2B 数字 3PL——对全流程结果负责、外部运力 + 统一 TMS + 伙伴分润；验证责任型模式可持续盈利二十年。详见项目资料库《联畅物流全景研究与肯尼亚复制蓝图》。
